Advanced Methods of AI · Worksheet 32
Logic

A query is a formula with free variables

Pizza(x) ∧ ∃t (hasTopping(x, t) ∧ CheeseTopping(t))

  • The picture of the pizzeria is an interpretation: a domain of objects and the extension of every predicate.
  • The answers are the values of the free variable x that make the formula true in it.
  • That is checking one model, not proving that something holds in every model. The difference will matter: does the robot know everything?
Advanced Methods of AI · Worksheet 33
EQL

EQL: the same formula, over Python objects

cheesy = a(Pizza)(toppings=a(CheeseTopping)).from_(pizzas)
EQLfirst-order logic
a(Pizza)a variable x with Pizza(x)
toppings=a(CheeseTopping)∃t (hasTopping(x, t) ∧ CheeseTopping(t)): some element of the list
.from_(pizzas)the objects x ranges over; left out: the registry, every object the robot created
cheesy.tolist()all values of x that satisfy the formula

Read it aloud: “a pizza with a cheese topping, from the pizzas”. Writing a query computes nothing; .tolist() evaluates it.

Advanced Methods of AI · Worksheet 34
EQL

Every and no, and naming variables

a(Pizza)(toppings=every_is(VegetableTopping)).from_(pizzas)
pizza   = a(Pizza).from_(pizzas)
topping = a(PizzaTopping).from_(pizza.toppings)
pizza.where(for_all(topping, HasType(topping, VegetableTopping)))

Pizza(x) ∧ ∀t (hasTopping(x, t) → VegetableTopping(t))

  • In a pattern, a(…) says some; every_is(…), none_is(…) say every, no. Both queries are one formula.
  • Other conditions: name the topping, then for_all or not_(exists(…)).
  • A path, pizza.toppings.spiciness == HOT, filters on a topping.
  • Every a(…) is a variable of its own; set_of(x, y) returns several at once.
Advanced Methods of AI · Worksheet 35
Logic

A class declaration is already a set of axioms

class MozzarellaTopping(CheeseTopping): ...
class Pizza:
    toppings: list[PizzaTopping]
class VegetarianPizza(Role[Pizza]): ...
KRROOD readsfirst-order logic
a subclass∀x (MozzarellaTopping(x) → CheeseTopping(x))
a typed attribute∀x ∀t (Pizza(x) ∧ hasTopping(x, t) → PizzaTopping(t))
a role of a pizza∀v (VegetarianPizza(v) → Pizza(roleTaker(v)))

All are necessary conditions: what follows from being a C. A definition adds the sufficient one, C(x) ↔ φ(x), and only that lets the robot decide what is a C. (Act 2)
